- The output example must match the goal text shown in the command example. [source: `src/xhtang_harness/cli.py`]

## Decisions

- Rewrite `USAGE.md` as a concise current-use guide with requirements, setup, CLI run examples, options, and troubleshooting. [source: user instruction, `src/xhtang_harness/cli.py`, `README.md`]
